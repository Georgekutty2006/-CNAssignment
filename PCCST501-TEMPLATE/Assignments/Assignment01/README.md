Assignment

## Title
How the Internet Delivers a Web Page.

## Objective
To understand how TCP/IP, DNS, HTTP, and client-server architecture work together to deliver a web page.
## Solution
The browser uses DNS to find the server's IP address, communicates using HTTP over TCP, and receives the requested web page from the server.
## Output
The requested web page is displayed correctly in the user's browser with reliable and secure communication.
## Conclusion
This assignment helped me understand the complete process of web page delivery using TCP/IP, DNS, HTTP, and client-server architecture.
